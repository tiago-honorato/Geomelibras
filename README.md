# Geomelibras 🤟🟥🟢🔷
**Geomelibras** é um jogo educativo desenvolvido para dispositivos móveis, voltado ao ensino e à prática da **Geometria** e da **Língua Brasileira de Sinais (LIBRAS).**

🎮 **Descrição do Jogo**

O jogo une elementos lúdicos e educacionais para proporcionar uma experiência interativa e acessível, usando recursos visuais, vídeos em LIBRAS e atividades relacionadas às formas geométricas (2D e 3D).

## 🚀 Como Instalar e jogar

* 📱 **Instalar no Android (APK):**
  1. Vá até a seção de [Releases](../../releases).
  2. Baixe o arquivo `.apk` da versão mais recente em **Assets**.
  3. No seu celular, abra o arquivo baixado para instalar (habilite a permissão de *fontes desconhecidas*, se solicitado).

---

## 📌 **Requisitos do Sistema**

Os requisitos podem variar de acordo com a versão do jogo e o dispositivo utilizado.

* **Sistema operacional:** Android
* **Memória RAM:** Recomenda-se pelo menos 2 GB de RAM
* **Armazenamento:** Espaço disponível para instalação do aplicativo
* **Tela:** Compatível com dispositivos touchscreen

---

## 🛠️ **Desenvolvimento**
O jogo foi desenvolvido utilizando a Unity6 Engine, com foco na criação de uma experiência educativa, acessível e interativa para o usuário.

### Tecnologias Utilizadas
- Unity6 Engine
- Linguagem C#
- Android
